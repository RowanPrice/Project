# Power plant simulator

How to run:
Go to app.py
run app.py
go to the server that pops up in the terminal
you will be taken to the map which shows all the buildings; click on the power plant
turn the power plant on and raise the control rods to increase the temperature of the reactor
go back to the map and then go to the administrative building
select a contract
your energy will start going towards the contract, generating you money
use the money to buy upgrades and such
